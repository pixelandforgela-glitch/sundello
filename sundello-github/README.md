# Sundello site files

The website that gets published is [`dist/`](dist/). Old drafts live in [`concepts/`](concepts/) and are not the live site.

How to preview, deploy, and change the site is in the repository root: [`../README.md`](../README.md) and [`../AGENTS.md`](../AGENTS.md). Follow those. Do not publish `concepts/`.

Images are architectural concepts and may differ from final construction specifications. Included font licenses remain with their assets.
